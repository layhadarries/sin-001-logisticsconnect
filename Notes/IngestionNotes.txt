"record". very cool, very nice special kind of class:
normally, you'd have to write a class like this:

private static class CleanedRow {
    private final String hubId;
    private final String province;
    private final String sortingCenter;
    private final Boolean active;

    public CleanedRow(String hubId, String province,
                      String sortingCenter, Boolean active) {
        this.hubId = hubId;
        this.province = province;
        this.sortingCenter = sortingCenter;
        this.active = active;
    }

    // getters, equals(), hashCode(), toString()...
}

that's a lot of boilerplate just to hold four values.

a record lets Java generate most of that for you:
private record CleanedRow(
    String hubId,
    String province,
    String sortingCenter,
    Boolean active
) {}
